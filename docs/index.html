Convierte y edita cualquier archivo con un clic Convert and edit any file with one click

Mantén Alt y haz clic sobre un archivo. Aparece una pequeña rueda junto a él: elige el formato, la herramienta o lo que quieras hacer. Sin abrir webs ni subir nada. Hold Alt and click a file. A small wheel appears next to it: pick the format, the tool or what to do. No websites, no uploads.

InstalarInstall

  1. Descarga Garlic-win32-x64.zip desde Releases.Download Garlic-win32-x64.zip from Releases.
  2. Clic derecho sobre el zip → Propiedades → marca Desbloquear.Right-click the zip → Properties → tick Unblock.
  3. Extrae todo en una carpeta (por ejemplo C:\Garlic) y abre Garlic.vbs.Extract everything to a folder (for example C:\Garlic) and open Garlic.vbs.
  4. La primera vez el atajo puede tardar hasta un minuto en estar listo: Windows analiza los archivos nuevos.The first time the shortcut can take up to a minute to be ready: Windows scans new files.

Aviso de SmartScreen: Garlic no está firmado con un certificado de pago, así que Windows puede mostrar «Windows protegió tu PC». Elige Más información → Ejecutar de todos modos. Cada versión publica su .sha256 para verificar la descarga, y el código completo es público. SmartScreen notice: Garlic is not signed with a paid certificate, so Windows may show “Windows protected your PC”. Choose More info → Run anyway. Every release publishes its .sha256 to verify the download, and the whole source is public.

FAQ

¿Funciona en macOS o Linux?Does it work on macOS or Linux?

Hoy solo está probado en Windows. macOS está implementado pero sin probar, y en Linux el atajo con clic no está disponible. Los informes de prueba son bienvenidos en GitHub.It is only tested on Windows today. macOS is implemented but untested, and the click shortcut is not available on Linux. Test reports are welcome on GitHub.

¿Sube mis archivos a algún sitio?Does it upload my files?

No. Las conversiones se hacen en tu equipo y el resultado se guarda junto al original.No. Conversions run on your machine and the result is saved next to the original.

¿Es gratis?Is it free?

Sí, con licencia MIT. Incluye ffmpeg (GPL) como componente aparte; los detalles están en el repositorio.Yes, MIT licensed. It ships ffmpeg (GPL) as a separate component; details are in the repository.

¿Cómo se actualiza?How do I update?

La app avisa con un icono de descarga cuando hay una versión nueva y muestra las novedades. Descargas el zip nuevo y reemplazas la carpeta; tus ajustes se conservan.The app shows a download icon when a new version exists, with what changed. Download the new zip and replace the folder; your settings are kept.
